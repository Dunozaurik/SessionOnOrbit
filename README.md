# Сессия на орбите

3D-квест с элементами головоломки: студент космического университета-станции
должен за одну сессию собрать подписи всех преподавателей в зачётке.

Движок: **Godot 4.7** (GDScript, рендерер Forward+).

## Скачать и играть

Ничего устанавливать не нужно, достаточно скачать архив, распаковать и запустить.

- **Windows:** [SessionOnOrbit-Windows.zip](../../releases/latest) (около 50 МБ, раздел Assets на странице релиза). Распакуйте и запустите `SessionOnOrbit.exe`. Если Windows предупредит о неизвестном издателе, нажмите «Подробнее» и «Выполнить в любом случае».
- **macOS:** [SessionOnOrbit-macOS.zip](../../releases/latest) (около 72 МБ, Intel и Apple Silicon, раздел Assets на странице релиза). Распакуйте и откройте `Сессия на орбите.app` через правый клик и «Открыть» (приложение не подписано, при обычном двойном щелчке macOS может отказаться его запускать). Если пишет, что приложение «повреждено», выполните в терминале: `xattr -cr "Сессия на орбите.app"`.

## Как открыть проект в Godot
1. Запустить Godot → **Import** → выбрать `project.godot` в этой папке.
2. **F5** — запуск игры с главного меню, **F6** — запуск открытой сцены.

## Сборка и запуск готовой игры

Готовые сборки лежат в `build/` (папка в `.gitignore`, в репозиторий не попадает).

- **Windows:** `build/windows/SessionOnOrbit.exe` — один файл, запускается двойным щелчком, ничего ставить не нужно.
- **macOS:** `build/macos/SessionOnOrbit.zip` — внутри `Сессия на орбите.app` (универсальная сборка для Intel и Apple Silicon). Приложение не подписано, поэтому при первом запуске macOS может написать, что оно «повреждено» или от неизвестного разработчика: нужно нажать на него правой кнопкой и выбрать «Открыть» либо выполнить в терминале `xattr -cr "Сессия на орбите.app"`.

Пересборка (нужны шаблоны экспорта Godot 4.7.2, настройки лежат в `export_presets.cfg`):

```
godot --headless --path . --export-release "Windows" build/windows/SessionOnOrbit.exe
godot --headless --path . --export-release "macOS" build/macos/SessionOnOrbit.zip
```

## Управление
| Клавиша | Действие |
|---------|----------|
| W A S D | Ходьба (работает и на русской раскладке) |
| Мышь | Обзор |
| Shift | Бег |
| Пробел | Прыжок |
| E | Взаимодействие |
| Tab | Зачётка: какие предметы сданы, какой следующий и где его искать |
| Q | Выйти из диалога в любой момент (разговор можно начать заново) |
| Esc | Пауза |

## Автозагрузки
- **GameState** — состояние прохождения, список всех пасхалок (`EASTER_EGGS`).
- **Sfx** — `Sfx.play("pickup")`, `Sfx.play_at("ding", позиция)`; кнопки озвучиваются сами.
- **Dialogue** — `Dialogue.start([{"speaker": "Имя", "text": "..."}])`, поддерживает
  варианты ответа (`"choices"`) и вызов функции на реплике (`"call"`).
- **AndreyTrip** — сюжетка Андрея (чат, полёт шаттла) идёт в любом отсеке.
- **Transition** — `Transition.go("res://...tscn", "ИмяМаркера")`: переход с затемнением.

## Как добавить новый отсек
1. Сцена с корнем `Node3D` и скриптом, наследующим `Room` (`extends Room`, в `_ready` — `super._ready()`).
2. Внутри: Player, HUD, PauseMenu, дверь `props/door.tscn` обратно в атриум
   (`target_scene` = atrium.tscn, `spawn_id` = маркер у двери в атриуме) и `Marker3D` в группе `spawn`.
3. В атриуме у двери отсека снять `locked` и прописать `target_scene` и `spawn_id`.
4. Состояние заданий хранить в `GameState.flags`, чтобы оно не сбрасывалось при выходе.

## Как добавить интерактивный объект
1. Создать `StaticBody3D` с мешем и `CollisionShape3D`.
2. Повесить скрипт `scripts/interaction/interactable.gd`, задать `prompt`.
3. В скрипте уровня подключиться к сигналу `interacted`.
