# Сессия на орбите

3D-квест с элементами головоломки: студент космического университета-станции
должен за одну смену собрать подписи всех преподавателей в зачётке.

Движок: **Godot 4.7** (GDScript, рендерер Forward+).

## Как открыть
1. Запустить Godot → **Import** → выбрать `project.godot` в этой папке.
2. **F5** — запуск игры с главного меню, **F6** — запуск открытой сцены.

## Управление
| Клавиша | Действие |
|---------|----------|
| W A S D | Ходьба (работает и на русской раскладке) |
| Мышь | Обзор |
| Shift | Бег |
| Пробел | Прыжок |
| E | Взаимодействие |
| Tab | Зачётка: какие предметы сданы, какой следующий и где его искать |
| Esc | Пауза |

## Структура
```
scenes/
  levels/     отсеки станции: atrium (хаб), programming (компьютерный класс)
  npc/        npc.tscn — персонаж-заглушка с именем
  player/     игрок от первого лица
  props/      предметы: шпора, дверь-шлюз
  ui/         меню, HUD, пауза с журналом пасхалок, диалоги, терминал-головоломка, затемнение
scripts/
  autoload/   GameState — подписи, шпоры, флаги, пасхалки; Sfx — звуки
  data/       тексты (истории Андрея и т. п.)
  interaction/Interactable, Npc, CheatSheet
  levels/     логика уровней и сюжетных линий
  player/ ui/
assets/       модели, звуки, музыка, шрифты
tools/        generate_sfx.py — генератор собственных звуков
ASSETS.md     перечень ассетов и лицензий
```

## Автозагрузки
- **GameState** — состояние прохождения, список всех пасхалок (`EASTER_EGGS`).
- **Sfx** — `Sfx.play("pickup")`, `Sfx.play_at("ding", позиция)`; кнопки озвучиваются сами.
- **Dialogue** — `Dialogue.start([{"speaker": "Имя", "text": "..."}])`, поддерживает
  варианты ответа (`"choices"`) и вызов функции на реплике (`"call"`).
- **AndreyTrip** — сюжетка Андрея (чат, полёт шаттла) идёт в любом отсеке.
- **Transition** — `Transition.go("res://...tscn", "ИмяМаркера")`: переход с затемнением.

## Как добавить новый отсек
1. Сцена с корнем `Node3D` и скриптом, наследующим `Room` (`extends Room`, в `_ready` — `super._ready()`).
2. Внутри: Player, HUD, PauseMenu, дверь `props/door.tscn` обратно в атриум
   (`target_scene` = atrium.tscn, `spawn_id` = маркер у двери в атриуме) и `Marker3D` в группе `spawn`.
3. В атриуме у двери отсека снять `locked` и прописать `target_scene` и `spawn_id`.
4. Состояние заданий хранить в `GameState.flags`, чтобы оно не сбрасывалось при выходе.

## Как добавить интерактивный объект
1. Создать `StaticBody3D` с мешем и `CollisionShape3D`.
2. Повесить скрипт `scripts/interaction/interactable.gd`, задать `prompt`.
3. В скрипте уровня подключиться к сигналу `interacted`.
