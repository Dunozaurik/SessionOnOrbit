# Сессия на орбите — курсовой проект (Godot 4.7, GDScript)

**Перед работой прочитай [docs/HANDOFF.md](docs/HANDOFF.md)** — там контекст проекта, стиль, архитектура,
технические грабли и список того, что осталось. Дизайн игры — [docs/design.md](docs/design.md).

Главное коротко:
- Общаться на русском.
- **Не коммитить и не пушить** — это делает пользователь. В конце работы дать команды `git add -A` / `git commit` / `git push`.
- Каждое изменение проверять в Godot (headless-тест сценария + скриншоты) и честно писать, что проверено.
- Файлы проекта не править через PowerShell `Set-Content` — он пишет BOM и ломает `.tscn`.
- В текстах игры не использовать эмодзи и редкие символы (`∞`, `∑`, `✓`) — шрифт их не рисует.
- Из диалога можно выйти на любой реплике (Q): подписи, предметы и этапы заданий менять только в `"call"`
  нужной реплики, не до `Dialogue.start()`.

  реальные друзья пользователя, шутки про них добрые.
