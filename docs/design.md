# «Сессия на орбите» — дизайн-документ

> Рабочий документ: по нему делаем игру, из него же потом собирается раздел 1
> пояснительной записки (описание, правила и механики, сцены и переходы).

## Суть

**Жанр:** 3D-квест с элементами головоломки, вид от первого лица.
**Сеттинг:** «Орбитмех» — технический университет на орбитальной станции.
**Цель игрока:** за одну смену собрать **6 подписей** в зачётке, сдать её в деканат и закрыть сессию.
**Тон:** абсурдная сатира на студенческую жизнь, вузовские пасхалки, мета-шутки.

Основной цикл: ходишь по хабу → заходишь в отсек → говоришь с преподавателем →
выполняешь его задание (у каждого своя механика) → получаешь подпись → следующий отсек.
Предметы сдаются **строго по порядку**: Заглушкин → Программирование → Высшая математика →
ФОМ → Физика → БЖД → Деканат. Дверь следующего отсека открывается после подписи за предыдущий.
Порядок и текущая цель — в зачётке по **Tab**.

## Карта станции

```
                 ┌───────────────── АТРИУМ (хаб) ─────────────────┐
                 │  [Выш. матем.]     [ДЕКАНАТ]      [ФОМ]         │
                 │                                                 │
   спасательная  │                                                 │  док: табло,
   капсула  ─────┤  Moodle   кофе      Заглушкин                   ├── терминал связи
   лифт (1957)   │                                                 │  с Гатчиной-4
                 │                                                 │  [БЖД: шлюз]
                 │  [Физика]        расписание      [Программир.]  │
                 └─────────────────────────────────────────────────┘
```

Каждый отсек — **отдельная сцена**. Переход через дверь-шлюз с затемнением;
игрок появляется у соответствующей двери. Всё состояние прохождения хранится
в автозагрузке `GameState`, поэтому при возвращении в атриум ничего не сбрасывается.

### Сцены и переходы

| Сцена | Откуда попасть | Куда ведёт |
|-------|----------------|------------|
| Главное меню | запуск игры | Атриум |
| Атриум (хаб) | меню, любой отсек | все отсеки, деканат, концовка «капсула» |
| Лаборатория физики | атриум | атриум |
| Компьютерный класс | атриум | атриум |
| Кафедра высшей математики | атриум | атриум |
| Аудитория ФОМ | атриум | атриум |
| Шлюз БЖД (+ выход в космос) | атриум | атриум |
| Деканат | атриум | экран концовки |
| Экран концовки (титры) | деканат, капсула | главное меню |

## Преподаватели и задания

Все преподаватели вымышленные (позже некоторых можно переделать под реальных).

### 0. Проф. Заглушкин — атриум ✅ готово
Временная модель-капсула. Подписывает сразу, мета-шутки про курсовой.
Вариант ответа «Можно автоматом?» ставит флаг для секретной концовки «Автомат».

**Решение: остаётся сквозным приколом.** В финальной версии, когда все получат нормальные
модели, он так и останется единственной серой капсулой и будет на это жаловаться
(«Всем сделали модельки. Всем, кроме меня. Я подожду. Я же временный»).
Идеи для него можно дописывать сюда.

### 1. Доц. Невесомова — лаборатория физики
**Механика:** физика предметов + платформинг.
Сломался генератор гравитации: ящики, стулья и колбы парят в воздухе.
Нужно найти **3 предохранителя**:
- один парит под потолком — допрыгнуть по летающим ящикам;
- один в шкафу с приборами;
- третий… у самой Невесомовой в кармане («ой, он у меня был»).

Вставил все три — гравитация возвращается, **всё с грохотом падает** (физика RigidBody). Подпись.

### 2. Ст. преп. Синтаксисов — компьютерный класс
**Механика:** головоломка в интерфейсе терминала + поиск предмета.
«Компилятор станции не собирает расписание». На терминале фрагмент кода:
нужно кликнуть по строке с ошибкой (3 раунда, всё абсурднее).
В 3-м раунде компилятор пишет: «ожидалась `;` в строке 42», а строки 42 нет —
точка с запятой **физически укатилась**. Ищем светящуюся «;» по аудитории как 3D-предмет,
вставляем в терминал → компилируется → подпись.
(«90% времени ищем пропущенную точку с запятой, 10% — любуемся звёздами».)

### 3. Проф. Интегралов — кафедра высшей математики
**Механика:** кодовый замок (3 цифры).
Ведомость заперта в сейфе. Код — ответы на три примера, разбросанные по кафедре
(доска: (5)' = 0; черновик на столе: i² + 8 = 7; бумажка под стулом: интеграл от 0 до 2 от x dx = 2).
Неверный код: «Попыток осталось: бесконечно много. Я не зверь». После 4 ошибок сейф подсказывает,
где искать. Открыл сейф → подпись ставит сам Интегралов. Пасхалка: код 067 — «SIX SEVEN!».

### 4. Доц. Транзисторова — аудитория ФОМ
**Механика:** викторина на таймере. Пародия на тест в Moodle:
5 абсурдных вопросов, **20 секунд** («у вас было 20 минут, но это станция, тут всё быстрее»).
Для зачёта нужно 4 из 5. **Шпоры наконец-то полезны:** каждая найденная шпора
даёт +5 секунд. Провал — «Пересдача доступна немедленно. Как и в жизни — бесконечно».
Отсылка: «Лабонин тоже пытался. 47 раз».

### 5. Инструктор Перестрахов — шлюз БЖД
**Механика:** последовательность действий + короткий выход в открытый космос.
Выйти в космос строго по инструкции: скафандр → проверка кислорода →
страховочный трос → закрыть внутреннюю дверь → разгерметизация → открыть внешнюю.
Ошибся — смешная «смерть» («Вас унесло в сторону Гатчины-4. Андрей передаёт привет.
НЕЗАЧЁТ») и попытка заново. Снаружи забрать кружку инструктора, улетевшую за борт,
вернуться → подпись.
«Программирование сдали? Ха. Это БЖД».

### 6. Секретарь Справкина — деканат (финал)
Принимает зачётку только с **6 подписями**. Потом выясняется, что нужна
«справка о том, что вы студент»: очередь, музыка ожидания, печать —
и сессия закрыта. → экран концовки.

## Концовки

| Концовка | Условие | Суть |
|----------|---------|------|
| **Сессия сдана** (обычная) | 6 подписей → деканат | Титры, статистика: шпоры, пасхалки, время |
| **Отчислился сам** | спасательная капсула в атриуме, в любой момент | Улетаешь от сессии. Перекличка с кнопкой «Отчислиться» в меню |
| **Вместе до конца** | Андрей прилетел + обычная концовка | Андрей тоже в деканате: «Лабонин? Вы же числились пропавшим без вести». — «Пацаны, вы не поверите…» |
| **Новый декан** | найдены все пасхалки + обычная концовка | Справкина: «Декан застрял в лифте в 1957-м. Должность свободна». |
| **Автомат** | ответ «Можно автоматом?» Заглушкину + автомат с газировкой в деканате | Сессия закрыта автоматом. Газировочным. |

## Сквозные системы (уже есть)

- Диалоги с вариантами ответа (`Dialogue`), звуки (`Sfx`), состояние (`GameState`).
- Зачётка (подписи), шпоры (нужны в ФОМ), журнал пасхалок в паузе.
- Чат группы (уведомления от Андрея), сюжетка Андрея Лабонина, лифт и студент Петров.

## Порядок разработки

1. ✅ **Инфраструктура:** переходы между сценами (двери-шлюзы, точки появления, затемнение),
   перенос состояния атриума в `GameState`, расширенный атриум с дверями.
2. ✅ Компьютерный класс (Синтаксисов).
3. ✅ Кафедра высшей математики (Интегралов). Код сейфа — 072; пасхалка «Six seven» на коде 067.
4. ✅ Аудитория ФОМ (Транзисторова). Тест: 5 из 7 вопросов, 20 с + 5 с за шпору, зачёт от 4;
   пасхалка «Пересдача — мой путь» за 3 провала; доска почёта с Лабониным.
5. ✅ Лаборатория физики (Невесомова). Высота 9,5 м, гравитация игрока 0,35 (прыжок ~3 м),
   маршрут из 5 летающих ящиков (2 ходят туда-сюда) к предохранителю на ~8 м; предметы на RigidBody;
   пасхалка «Ньютон доволен» (яблоко до и после починки).
6. ✅ Шлюз БЖД (Перестрахов). Инструкция — только «стр. 2» (шаги 4–6); 4 вида «незачёта»;
   шлем-оверлей, трос до игрока, открытый космос с Землёй и указателем на Гатчину-4;
   пасхалка «Учебник БЖД в картинках» за 3 разных незачёта. Снаружи — магнитные ботинки
   (без прыжков, медленнее), ходить можно только внутри поручней; космический мусор с подписями.
   После зачёта Перестрахов запирает шлюз навсегда.
7. Деканат, концовки, титры.
8. Арт-проход: модели вместо заглушек, музыка; настройки; сборка под Windows (+ веб).
